# DISBOARD 서버 필터

DISBOARD에서 원하지 않는 서버를 숨기고, 숨긴 자리에 다음 목록의 서버를 채워 주는 Chrome 확장 프로그램입니다. 서버 이름·태그·소개글의 키워드뿐 아니라 온라인 인원, 리뷰 별점, 한자, 참가 링크 클릭 기록, New! 표시로도 목록을 걸러 볼 수 있습니다.

**현재 버전: 1.4.1 · PC용 Chrome · 별도 빌드 없이 설치**

- [최신 릴리스와 설치용 ZIP](https://github.com/blond11qq/disborad_flilter_chrome_extention/releases/latest)
- [전체 릴리스](https://github.com/blond11qq/disborad_flilter_chrome_extention/releases)
- [문제 신고](https://github.com/blond11qq/disborad_flilter_chrome_extention/issues)

이 저장소는 비공개입니다. 접근 권한이 있는 GitHub 계정으로 로그인해야 릴리스 파일을 받을 수 있습니다. 링크에서 404가 나오면 로그인 계정과 저장소 접근 권한을 확인하세요.

## 설치 전에 확인하기

- 데스크톱용 Google Chrome에서 사용합니다. 모바일 Chrome은 이 설치 안내의 대상이 아닙니다.
- 작동하는 주소는 `https://disboard.org/*`입니다. 한국어 페이지를 포함하며 Discord 앱이나 다른 서버 소개 사이트에는 적용되지 않습니다.
- Chrome 웹 스토어 설치가 아닙니다. GitHub 릴리스 ZIP을 압축 해제한 다음 Chrome의 개발자 모드에서 불러옵니다.
- 설치와 사용에 Node.js, npm, Python, 터미널은 필요하지 않습니다.
- 확장 프로그램 자체의 계정이나 로그인은 없습니다. 비공개 릴리스를 다운로드하는 데에는 GitHub 로그인이 필요합니다.
- 압축을 푼 폴더는 설치 후에도 보관해야 합니다. Chrome이 그 폴더의 파일을 직접 사용합니다.

## Chrome에 처음 설치하기

### 1. 설치용 ZIP 다운로드하기

1. [최신 릴리스](https://github.com/blond11qq/disborad_flilter_chrome_extention/releases/latest)를 엽니다.
2. 릴리스 아래의 **Assets**를 펼칩니다.
3. `disborad_flilter_chrome_extention-v1.4.1.zip`을 내려받습니다. 다른 버전이라면 해당 버전 번호가 붙은 설치용 ZIP을 선택합니다.
4. ZIP을 압축 해제합니다. macOS에서는 더블클릭하고, Windows에서는 우클릭 메뉴의 **압축 풀기** 또는 **모두 추출**을 사용합니다.

GitHub가 자동으로 붙이는 **Source code (zip)**과 **Source code (tar.gz)**은 소스 코드입니다. 처음 설치할 때는 위 이름의 설치용 ZIP을 선택하세요.

### 2. 폴더를 보관할 위치로 옮기기

1. 압축을 푼 폴더를 계속 보관할 위치로 옮깁니다. 예를 들어 문서 폴더 안에 확장 프로그램용 폴더를 만들 수 있습니다.
2. 폴더를 열어 `manifest.json`이 있는지 확인합니다.

설치할 폴더에는 다음 파일이 함께 들어 있어야 합니다.

```text
disborad_flilter_chrome_extention/
  manifest.json
  filter.js
  content.js
  content.css
  popup.html
  popup.js
  popup.css
  README.md
```

폴더가 한 겹 더 들어 있다면 `manifest.json`이 직접 들어 있는 안쪽 폴더를 선택합니다. ZIP 파일 자체나 `manifest.json` 파일 하나만 선택하지 않습니다.

### 3. Chrome에서 불러오기

1. Chrome 주소창에 `chrome://extensions`를 입력하고 Enter를 누릅니다.
2. 화면 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다. 영어 Chrome에서는 **Load unpacked**입니다.
4. `manifest.json`이 들어 있는 폴더를 선택합니다.
5. 목록에 **DISBOARD 서버 필터**가 나타나는지 확인합니다.
6. 해당 확장 프로그램의 사용 스위치가 켜져 있는지 확인합니다.

개발자 모드는 웹 스토어 외부의 로컬 확장 폴더를 불러오기 위해 사용합니다. 설치 절차는 [Chrome 공식 로컬 확장 설치 안내](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)에서도 확인할 수 있습니다.

### 4. 아이콘 고정하고 설정 열기

1. Chrome 오른쪽 위의 퍼즐 모양 **확장 프로그램** 버튼을 누릅니다.
2. **DISBOARD 서버 필터** 옆의 핀 버튼을 누릅니다.
3. 도구 모음에 나타난 확장 아이콘을 누릅니다.
4. **서버 필터** 설정창이 열리는지 확인합니다.

전용 아이콘 파일이 없어 Chrome의 기본 확장 아이콘으로 보일 수 있습니다. 확장 프로그램 이름으로 구분하세요.

### 5. DISBOARD 목록 열기

1. [DISBOARD 한국어 페이지](https://disboard.org/ko/)에서 서버 목록이 있는 페이지를 엽니다.
2. 설치 전에 열어 둔 DISBOARD 탭이라면 새로고침합니다.
3. 확장 아이콘을 눌러 원하는 조건을 저장합니다.

설정창은 다른 사이트에서도 열 수 있지만, 서버를 숨기는 동작은 DISBOARD 페이지에서만 실행됩니다.

## 처음 필터 적용하기

1. DISBOARD 서버 목록을 연 상태에서 확장 아이콘을 누릅니다.
2. **서버 필터 사용**이 켜져 있는지 확인합니다.
3. **숨길 키워드 추가**에 `대리, 홍보`를 입력합니다.
4. **키워드 추가**를 누릅니다.
5. **저장한 키워드** 목록에 두 단어가 나타나는지 확인합니다.
6. 설정창 바깥을 눌러 닫고 DISBOARD 목록을 확인합니다.

서버 이름·태그·소개글 중 한 곳에라도 `대리` 또는 `홍보`가 있는 서버가 숨겨집니다. 목록 위에는 다음과 같은 상태가 나타납니다.

```text
필터 · 표시 24개 · 숨김 12개
```

숫자는 예시입니다. 현재 탭에 불러온 카드 중 표시한 수와 숨긴 수이며 DISBOARD 전체 서버 수나 전체 검색 결과 수가 아닙니다. 숨김으로 목록이 부족해지면 다음 목록을 자동으로 요청할 수 있습니다.

처음 설치하면 **서버 필터 사용**만 켜져 있습니다. 키워드는 비어 있고 인원 제한과 추가 제외 조건은 모두 꺼져 있어, 조건을 저장하기 전에는 기본 설정으로 서버를 숨기지 않습니다.

## 키워드 관리하기

### 여러 키워드 추가하기

1. **숨길 키워드 추가**에 단어를 입력합니다.
2. 쉼표나 줄바꿈으로 단어를 구분합니다.
3. **키워드 추가**를 누릅니다.

다음 두 입력은 같은 세 키워드를 추가합니다.

```text
대리, 홍보, 성인
```

```text
대리
홍보
성인
```

띄어쓰기만으로는 키워드가 나뉘지 않습니다. `게임 모집`은 공백을 포함한 하나의 키워드입니다. 입력만 하고 설정창을 닫으면 저장되지 않으므로 버튼을 누르고 완료 메시지를 확인하세요.

### 일치 기준 확인하기

키워드는 포함된 문자열을 찾습니다. 정확히 같은 태그만 찾거나 정규식을 실행하는 기능은 없습니다.

| 저장한 키워드 | 일치하는 예 | 결과 |
| --- | --- | --- |
| `대리` | 태그 `발로란트대리` | 숨김 |
| `대리` | 소개글 `대리 모집합니다` | 숨김 |
| `대리` | 이름 `대리 전문 서버` | 숨김 |
| `game` | 소개글 `GAME community` | 숨김 |
| `게임 모집` | 소개글 `게임 모집 중` | 숨김 |
| `게임 모집` | 소개글 `게임을 함께 모집` | 이 키워드로는 숨기지 않음 |

영문 대소문자를 구분하지 않습니다. 앞뒤 공백을 제거하고 유니코드를 정규화해 비교합니다. 짧고 흔한 단어는 원하는 서버까지 숨길 수 있으므로 결과가 너무 적으면 구체적인 표현으로 바꿔 보세요.

기존에 저장한 키워드가 입력에 섞여 있으면 중복 안내가 나오고 해당 추가 작업을 저장하지 않습니다. 중복 단어를 빼고 다시 누릅니다. 같은 입력 안에서 반복한 단어는 하나로 정리합니다.

### 수정하기

1. **저장한 키워드**에서 바꿀 항목의 **수정**을 누릅니다.
2. 입력칸의 단어를 고칩니다. 수정할 때는 한 키워드만 입력합니다.
3. **수정 저장**을 누릅니다.

그만두려면 **취소**를 누릅니다. 다른 저장 키워드와 같게 수정하면 중복 안내가 나옵니다.

### 삭제하기

항목 옆의 **삭제**를 누릅니다. 별도 확인창 없이 바로 저장됩니다. 실수로 지웠다면 같은 키워드를 다시 추가합니다.

키워드를 모두 지워도 인원 범위나 추가 제외 조건이 켜져 있으면 해당 조건으로 계속 숨깁니다.

## 온라인 인원으로 거르기

1. **인원 · 리뷰 · 한자 · 방문 · New 필터**를 펼칩니다.
2. **온라인 인원 수**의 **최소 (이상)**와 **최대 (이하)**를 입력합니다.
3. **인원 범위 저장**을 누릅니다.

| 입력 | 표시하는 서버 |
| --- | --- |
| 최소 `50`, 최대 `500` | 온라인 50명 이상, 500명 이하 |
| 최소 `100`, 최대 비움 | 온라인 100명 이상 |
| 최소 비움, 최대 `30` | 온라인 30명 이하 |
| 둘 다 비움 | 온라인 인원으로 제한하지 않음 |

양 끝값을 포함합니다. 0 이상의 정수만 입력하며 최소가 최대보다 크면 저장하지 않습니다. 제한을 해제할 때도 두 칸을 비우고 **인원 범위 저장**을 눌러야 합니다.

이 값은 목록에 표시된 **온라인 인원**입니다. 전체 멤버 수나 음성 채널 접속 인원이 아닙니다. 인원 제한을 하나라도 설정하면 온라인 숫자를 확인할 수 없는 서버도 숨깁니다. 표시 숫자는 사이트가 제공한 값이며 실시간 인원을 별도로 조회하지 않습니다.

## 추가 제외 조건 사용하기

**인원 · 리뷰 · 한자 · 방문 · New 필터**에서 원하는 스위치를 켭니다. 스위치는 변경 즉시 저장됩니다.

| 설정 | 켜면 숨기는 서버 | 판단하지 않는 내용 |
| --- | --- | --- |
| 리뷰 별점 있는 서버 제외 | 목록에 실제 리뷰 별점 표시가 있는 서버 | 소개글의 별 문자나 별 이모지 |
| 한자 포함 서버 제외 | 이름·태그·소개글에 한자가 있는 서버 | 국적, 사용자 언어, 접속 국가 |
| 방문한 서버 제외 | 참가 링크 클릭 기록이 있는 서버 | 실제 Discord 가입 여부 |
| New! 표시 서버 제외 | 사이트가 New! 상태나 배지를 붙인 서버 | 이름·소개글의 단순한 `New` 문구 |

한자 조건에는 일본어의 한자도 포함됩니다. 한글·히라가나·가타카나만 있는 문장은 이 조건으로 숨기지 않습니다. 한국어 서버라도 소개글에 한자가 있으면 숨겨질 수 있습니다.

조건은 함께 적용됩니다. **하나라도 숨김 조건에 걸리면 숨깁니다.** 온라인 50~500명 범위와 한자 제외를 켰다면 인원 범위를 만족하더라도 이름에 한자가 있는 서버는 숨깁니다.

## 방문 기록 이해하기

DISBOARD의 **참가** 링크를 누르면 서버 ID를 현재 Chrome 프로필에 저장합니다. 목록과 서버 상세 페이지의 참가 링크가 대상이며 마우스 가운데 버튼으로 여는 동작도 처리합니다.

- 기록된 서버의 이름 옆에 **방문함** 배지가 붙습니다.
- 새로고침하거나 다른 DISBOARD 목록에서 같은 서버를 만나도 기록을 사용합니다.
- 같은 Chrome 프로필의 다른 탭에도 저장된 기록을 반영합니다.
- **방문한 서버 제외**를 켜면 기록된 서버를 숨깁니다. 끄면 다른 조건에 걸리지 않는 서버를 다시 볼 수 있습니다.

**방문함은 참가 링크를 눌렀다는 뜻입니다.** Discord에서 초대를 수락하지 않았거나 초대가 만료되어도 기록될 수 있습니다. 목록이나 상세 페이지를 보기만 한 것은 방문 기록이 아닙니다. 우클릭 메뉴로 링크를 여는 동작은 기록을 보장하지 않습니다.

설치 전 클릭 이력이나 Discord의 기존 가입 서버를 가져오지 않습니다. 가입 성공, 현재 가입 상태, 탈퇴 여부도 확인하지 않습니다. **서버 필터 사용**을 꺼도 확장 프로그램 자체가 켜져 있으면 참가 링크 클릭 기록은 계속 저장합니다.

현재 설정창에는 방문 기록 목록 보기, 서버별 기록 삭제, 방문 기록 전체 삭제 버튼이 없습니다. 백업 가져오기도 기존 방문 기록을 삭제하는 용도로 사용할 수 없습니다.

## 자동으로 다음 목록 채우기

카드를 숨기면 주변 카드가 빈칸을 채우도록 다시 배치합니다. 다음 페이지의 카드도 앞 페이지의 빈자리에 이어 붙입니다. 화면 너비에 따라 3열·2열·1열로 표시하며 마지막 줄에는 남는 칸이 있을 수 있습니다.

보이는 카드가 처음 불러온 목록 수보다 적어지면 다음 페이지를 순서대로 가져옵니다. 초기 목표는 현재 목록 수를 기준으로 하며 보통 24개입니다. 목록 아래 **더 불러오기**를 누르면 표시 목표를 24개 늘려 추가 로딩을 시도합니다.

- 추가 카드에도 같은 필터를 적용합니다.
- 같은 서버가 다시 나오면 서버 ID로 중복을 제거합니다.
- 확장 프로그램이 추가한 카드의 긴 설명은 **설명 더보기**와 **설명 접기**로 펼치고 접을 수 있습니다.
- 자동 채우기를 시작한 탭에서는 확장 프로그램이 추가 로딩을 담당합니다. 더 보려면 아래쪽 **더 불러오기**를 사용합니다.
- 조건에 맞는 카드가 충분해지거나 마지막 목록에 도달하면 멈춥니다.
- 한 번의 자동 채우기는 최대 100페이지까지 확인합니다. 사이트가 더 작은 페이지 한도를 알려 주면 먼저 멈춥니다. 계속할 수 있는 경우에는 버튼으로 다시 불러옵니다.

목록 위에는 **빈자리를 채우는 중…**과 진행 페이지 수가 표시됩니다. 조건이 강하면 여러 페이지를 읽어도 표시 수가 거의 늘지 않을 수 있습니다. 새로 불러온 카드는 현재 탭에만 있으며 백업에 저장되지 않습니다.

요청은 한 번에 하나씩 처리하고 다음 자동 요청 전에 대기합니다. 요청 제한이나 서버 오류가 발생하면 안내한 시간 뒤 최대 두 번 재시도합니다. `HTTP 403`은 자동 재시도하지 않습니다. 요청 하나의 응답 시간이 15초를 넘으면 중단하고 안내를 표시합니다.

사이트가 제공하는 목록 범위 안에서만 동작합니다. 모든 서버를 검색하거나 접근 제한을 우회하는 기능은 아닙니다. 페이지 구조나 요청 방식이 바뀌면 동작하지 않을 수 있습니다.

## 백업 내보내기와 가져오기

### 백업 파일 다운로드하기

1. 아직 저장하지 않은 키워드나 인원 범위가 있다면 먼저 각각의 저장 버튼을 누릅니다.
2. 설정창 아래 **내보내기**를 누릅니다.
3. 다운로드한 `disboard-backup.json`을 보관합니다.

백업에는 저장된 키워드, 필터 사용 여부, 온라인 범위, 네 가지 추가 제외 스위치, 방문 서버 ID가 들어갑니다. 저장 전 입력 내용, 현재 목록, 서버 소개글, Discord 계정 정보는 들어가지 않습니다.

방문 기록이 담긴 파일이므로 공유 전에 내용을 확인하세요. 확장 프로그램을 삭제하거나 Chrome 프로필을 바꾸기 전에 내보내 두는 것이 좋습니다.

### 다른 Chrome이나 컴퓨터에서 가져오기

1. 새 환경에 확장 프로그램을 설치합니다.
2. 설정창의 **가져오기**를 누릅니다.
3. 보관한 `disboard-backup.json`을 선택합니다.
4. 가져오기 완료 메시지를 확인합니다.
5. 키워드 목록과 추가 필터를 확인합니다.

| 항목 | 가져오기 결과 |
| --- | --- |
| 키워드 | 현재 목록에 파일의 키워드를 합치고 중복 제거 |
| 방문 기록 | 현재 기록에 파일의 기록을 합치고 중복 제거 |
| 필터 사용 여부 | 파일의 값으로 변경 |
| 온라인 최소·최대 | 파일의 값으로 변경 |
| 리뷰·한자·방문·New 제외 | 파일의 값으로 변경 |

기존 키워드가 `대리`, 파일의 키워드가 `홍보`라면 결과는 `대리, 홍보`입니다. 빈 키워드나 방문 목록을 가져와도 기존 내역이 지워지지 않습니다. 과거 시점의 데이터와 똑같이 덮어쓰는 복원 기능은 아닙니다.

파일의 필터 사용 여부가 꺼져 있으면 필터도 꺼집니다. 가져온 뒤 결과가 예상과 다르면 이 스위치부터 확인하세요.

### 예전 키워드 파일 사용하기

예전 형식인 `{"version":1,"keywords":["대리","홍보"]}` 또는 `["대리","홍보"]`도 가져올 수 있습니다. 이 형식은 키워드만 합치며 현재 인원 범위·스위치·방문 기록은 유지합니다.

전체 백업은 버전 2 형식입니다. 가져올 파일은 10MB 이하이고 파일의 키워드는 10,000개 이하·각 1,000자 이하, 방문 ID는 100,000개 이하의 숫자 문자열이어야 합니다. 잘못된 JSON이나 설정 값은 오류로 안내합니다. 파일 검사나 저장에 실패하면 기존 저장 데이터를 유지합니다.

일반 사용에서는 JSON을 직접 편집할 필요가 없습니다. 내보낸 파일을 그대로 보관하고 설정창에서 가져오세요.

## 업데이트하기

GitHub 릴리스로 설치한 버전은 새 릴리스를 직접 내려받아 적용합니다.

1. 현재 확장 프로그램에서 **내보내기**로 백업합니다.
2. [최신 릴리스](https://github.com/blond11qq/disborad_flilter_chrome_extention/releases/latest)에서 새 설치용 ZIP을 받습니다.
3. 임시 위치에 압축을 풉니다.
4. **처음 설치할 때 선택한 기존 폴더** 안의 파일을 새 파일로 교체합니다. 폴더를 한 겹 더 넣지 않도록 `manifest.json` 위치를 확인합니다.
5. `chrome://extensions`를 엽니다.
6. 기존 **DISBOARD 서버 필터** 카드의 새로고침 모양 버튼을 누릅니다.
7. 확장 프로그램의 버전 표시가 새 버전인지 확인합니다.
8. 열려 있는 DISBOARD 탭도 새로고침합니다.
9. 설정창을 열어 저장된 조건을 확인합니다.

같은 설치 항목과 폴더를 유지해 업데이트하면 기존 로컬 설정과 방문 기록을 계속 사용할 수 있습니다. 기존 확장 프로그램을 먼저 삭제하지 마세요. 다른 폴더에서 새 설치 항목으로 불러오면 별도 확장 프로그램으로 취급되어 기존 데이터가 보이지 않을 수 있습니다. 그 경우 백업 JSON을 가져옵니다.

## 잠시 끄거나 삭제하기

### 숨김 기능만 끄기

설정창 맨 위 **서버 필터 사용**을 끕니다. 조건을 지우지 않고 숨김을 해제합니다. 참가 링크 기록과 방문함 배지는 계속 사용할 수 있습니다. 다시 켜면 저장한 조건을 적용합니다.

### 확장 프로그램 전체 끄기

`chrome://extensions`에서 **DISBOARD 서버 필터** 카드의 사용 스위치를 끄고 DISBOARD 탭을 새로고침합니다. 다시 사용하려면 스위치를 켜고 탭을 새로고침합니다. 비활성화는 제거와 다르므로 설치 항목의 저장 데이터를 유지합니다.

### 삭제하기

1. 다시 사용할 데이터가 필요하면 **내보내기**로 먼저 백업합니다.
2. `chrome://extensions`에서 **DISBOARD 서버 필터**의 **삭제**를 누릅니다.
3. Chrome의 삭제 확인을 완료합니다.
4. DISBOARD 탭을 새로고침합니다.

제거하면 로컬 설정과 방문 기록도 삭제됩니다. 설치 폴더는 Chrome에서 확장 프로그램을 제거한 뒤 정리할 수 있습니다.

## 문제 해결하기

| 증상 | 확인하고 할 일 |
| --- | --- |
| 릴리스 링크에서 404가 나옴 | 저장소 접근 권한이 있는 GitHub 계정으로 로그인했는지 확인합니다. 권한이 없으면 저장소 소유자에게 접근을 요청합니다. |
| ZIP을 설치할 수 없음 | 먼저 압축을 풉니다. 로드 버튼에서 `manifest.json`이 들어 있는 폴더를 선택합니다. |
| 매니페스트가 없거나 불러올 수 없다는 오류 | 상위 폴더나 ZIP 내부를 선택하지 않았는지 확인합니다. 누락된 파일이 있으면 설치용 ZIP을 다시 받아 압축을 풉니다. |
| 아이콘이 보이지 않음 | 퍼즐 메뉴에서 이름을 찾아 고정합니다. 확장 프로그램 사용 스위치도 확인합니다. |
| 설정했는데 서버가 숨겨지지 않음 | DISBOARD 주소인지, 필터가 켜졌는지, 키워드 추가나 인원 저장을 눌렀는지 확인합니다. 설치 전 열린 탭은 새로고침합니다. |
| 너무 많은 서버가 사라짐 | 흔한 키워드를 지우거나 구체화합니다. 인원 범위를 비우고 저장한 뒤 추가 스위치를 하나씩 꺼서 원인을 확인합니다. |
| 표시 수가 계속 적음 | 조건에 맞는 서버가 부족할 수 있습니다. 자동 채우기 진행·오류 안내를 확인하고 조건을 완화합니다. |
| New라는 단어가 있는데 숨겨지지 않음 | New 제외는 사이트의 실제 배지 기준입니다. 단어 자체를 숨기려면 키워드 `new`를 추가합니다. |
| 인원이 맞는데 숨겨짐 | 전체 인원이 아닌 온라인 인원인지 확인합니다. 다른 키워드·추가 제외 조건도 확인합니다. |
| 가입하지 않은 서버에 방문함 표시 | 참가 링크를 눌렀다면 초대를 수락하지 않아도 저장될 수 있습니다. 가입 상태와 일치하지 않습니다. |
| 다른 컴퓨터에서 설정이 보이지 않음 | Chrome 계정 자동 동기화를 사용하지 않습니다. 원래 환경에서 내보낸 JSON을 가져옵니다. |
| 저장 또는 가져오기 실패 | 안내에 따라 다시 시도합니다. JSON 크기와 형식도 확인합니다. 실패 메시지가 있으면 저장된 것으로 간주하지 마세요. |
| HTTP 403 | 사이트가 요구하는 로그인이나 확인 절차를 DISBOARD 탭에서 직접 완료한 뒤 재시도합니다. |
| HTTP 429 | 요청 제한입니다. 안내한 대기 시간을 기다립니다. 계속 제한되면 자동 재시도가 멈춘 뒤 충분히 기다렸다가 재시도합니다. |
| HTTP 500·502·503·504 | 사이트 서버 오류일 수 있습니다. 재시도를 기다리고 계속 실패하면 나중에 다시 시도합니다. |
| 시간 초과나 네트워크 오류 | 연결과 사이트 접속 상태를 확인합니다. 기존 목록은 남으므로 **더 불러오기**로 다시 시도할 수 있습니다. |
| 마지막 목록 표시 | 사이트가 제공한 목록을 끝까지 확인했습니다. 검색어나 사이트 태그 조건을 바꿔 탐색합니다. |
| 업데이트 후 이전 동작이나 오류가 남음 | 기존 설치 폴더를 교체했는지 확인합니다. 확장 카드와 DISBOARD 탭을 모두 새로고침합니다. |

필터를 완전히 끄고 탭을 새로고침했을 때 DISBOARD 자체가 정상적으로 보이는지도 확인하세요. 다른 확장과 충돌이 의심되면 해당 확장을 잠시 꺼서 비교할 수 있습니다.

해결되지 않으면 [Issues](https://github.com/blond11qq/disborad_flilter_chrome_extention/issues)에 확장 버전, Chrome 버전, 운영체제, DISBOARD 주소, 재현 순서, 오류 메시지를 남깁니다. 스크린샷의 계정 정보나 백업에 든 방문 기록은 가리고 올리세요.

## 권한과 개인정보

`storage` 권한으로 설정과 방문 서버 ID를 `chrome.storage.local`에 저장합니다. 데이터는 현재 Chrome 프로필의 확장 저장소에 보관하며 다른 프로필·컴퓨터와 자동 동기화하지 않습니다.

콘텐츠 스크립트는 `https://disboard.org/*`에서만 실행합니다. 추가 목록은 현재 DISBOARD 주소에 같은 출처 요청으로 가져옵니다. 사이트 로그인 상태가 있다면 그 사이트에 대한 요청에 사용될 수 있습니다. 필터 키워드와 방문 기록을 별도 외부 서버로 전송하는 코드는 없습니다.

Discord 토큰 입력이나 Discord 계정 권한 승인이 필요하지 않습니다. 실제 가입 상태도 조회하지 않습니다. DISBOARD나 초대 링크로 이동한 서비스의 일반적인 접속 처리는 각 서비스 정책을 따릅니다.

확장 제거, Chrome 프로필 삭제, 확장 저장소 초기화로 데이터가 사라질 수 있습니다. 다시 사용할 데이터는 JSON으로 백업하세요.

## 소스 코드와 검증 정보

일반 사용자는 릴리스 ZIP만 설치하면 됩니다. 소스를 내려받는 경우에도 저장소 루트의 `manifest.json`이 있는 폴더를 Chrome에서 불러올 수 있습니다.

| 파일 | 역할 |
| --- | --- |
| `manifest.json` | 이름·버전·권한·DISBOARD 실행 범위 |
| `filter.js` | 키워드와 조건 판단, 백업 형식 처리 |
| `content.js` | 서버 숨김, 방문 기록, 다음 목록 로딩 |
| `content.css` | 목록 배치, 방문 배지와 설명 버튼 스타일 |
| `popup.html`, `popup.js`, `popup.css` | 설정창, 저장, 가져오기와 내보내기 |
| `tests/` | 필터·백업 단위 테스트와 브라우저 검증 스크립트 |

개발자가 단위 테스트를 실행하려면 Node.js 18 이상에서 저장소 루트에 다음 명령을 입력합니다. 외부 npm 패키지 설치는 필요하지 않습니다.

